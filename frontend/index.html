➕ Build Recognition Index

Processes all images in the Dataset/ folder, extracts face embeddings using FaceNet, and saves a FAISS index to disk.

📁 Dataset Structure
  • 📂
    Place images in Dataset/<person_name>/
    e.g. Dataset/messi/img1.jpg
  • 🖼
    Supported formats
    JPG, PNG, BMP, WEBP, JFIF
  • ⚡
    Use 5–20 images per person
    More images → better accuracy
  • 🔁
    Re-run enrollment after adding new people
    Index is rebuilt every time.
